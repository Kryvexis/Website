# Kryvexis OS Portal V3

A more aggressive, more interactive Next.js concept build for GitHub + Vercel.

## Local
```cmd
cd /d C:\dev\NEW_WEBSITE
npm install
npm run dev
```

## GitHub
```cmd
cd /d C:\dev\NEW_WEBSITE
git init
git add .
git commit -m "Build Kryvexis OS Portal V3"
git branch -M main
git remote add origin https://github.com/Kryvexis/Website.git
git push -u origin main
```

## Vercel
Set **Framework Preset** to **Next.js** and leave **Output Directory** blank.
