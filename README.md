```cmd
cd /d C:\dev\NEW_WEBSITE
npm install
npm run dev
```

## Push to GitHub
```cmd
cd /d C:\dev\NEW_WEBSITE
git init

git branch -M main
git remote add origin https://github.com/Kryvexis/Website.git
git push -u origin main
```
